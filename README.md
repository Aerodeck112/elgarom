# Backup elgarom.ro (2026-11-06)

Copie făcută înainte de mutarea hostingului, ca bază pentru site-ul nou.

- `texte/` – textele fiecărei pagini (Acasă, Despre Noi, Tehnologie, Contact) în `.md` și HTML brut; `texte/pagini-complete/` – tot textul vizibil, inclusiv meniu, subsol și date de contact.
- `imagini-originale/` – toate cele 42 de fișiere din biblioteca Media WordPress, la rezoluția originală (organizate pe an/lună).
- `mirror/` – oglinda completă a site-ului (HTML, CSS, JS, fonturi, imagini), navigabilă offline: deschide `mirror/elgarom.ro/index.html`.
- `wp-api/` – export JSON din API-ul WordPress (pagini, media, categorii) + sitemap.
