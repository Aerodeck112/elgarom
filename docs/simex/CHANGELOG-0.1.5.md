Versiunea 0.1.5

- Calculator nou: Ștanțe și matrițe — cost și preț (modelul FEPO v35). Fișierul Excel se încarcă din Calcul de costuri → Modele Excel.
- Calculatoarele se completează acum ca formular: câmpuri cu etichete, unități și explicații, tabele doar cu rândurile folosite și buton «Adaugă rând». Foaia Excel rămâne disponibilă.
- Buton «Creează ofertă din acest calcul»: oferta se deschide completată cu clientul, poziția, cantitatea, prețul și costul.
- Reparat: câmpurile din formulare erau înghesuite pe o singură coloană îngustă.
- Valorile negative de cost sau preț sunt semnalate ca avertizare.
- Panoul principal: grafice și liste aranjate pe două coloane.
